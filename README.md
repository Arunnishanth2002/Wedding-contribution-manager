# Wedding Contribution Management System

This is a full-stack web application built using Spring Boot to manage and track wedding contribution entries (moy system).

## 🚀 Features
- Add and manage contribution entries
- Search records by name and village
- Store data using MySQL database
- Export data to Excel format
- Simple and user-friendly interface using Thymeleaf

## 🛠️ Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- Apache POI

## 📌 Use Case
This application helps users maintain records of contributions given during events like weddings and allows easy retrieval and reporting.

## ▶️ How to Run
1. Clone the repository
2. Configure MySQL in `application.properties`
3. Run the Spring Boot application
4. Access the app at `http://localhost:8080`
